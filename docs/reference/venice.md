# Largest Sea Levels in Venice

The `venice` data frame has 51 rows and 10 columns. The jth column
contains the jth largest sea levels in Venice, for the years 1931-1981.
Only the largest six measurements are available for the year 1935; the
corresponding row contains four missing values. The years for each set
of measurements are given as row names.

## Usage

``` r
venice
```

## Format

A data frame with 51 rows and 10 columns.

## Source

Smith, R. L. (1986) Extreme value theory based on the *r* largest annual
events. *Journal of Hydrology*, **86**, 27-43.
[doi:10.1016/0022-1694(86)90004-1](https://doi.org/10.1016/0022-1694%2886%2990004-1)
