# Annual Maximum Sea Levels at Port Pirie, South Australia

A numeric vector of length 65 containing annual maximum sea levels, in
metres, from 1923 to 1987 at Port Pirie, South Australia.

## Usage

``` r
portpirie
```

## Format

A numeric vector containing 65 observations.

## Source

Coles, S. G. (2001) *An Introduction to Statistical Modelling of Extreme
Values*. London: Springer.
[doi:10.1007/978-1-4471-3675-0](https://doi.org/10.1007/978-1-4471-3675-0)
