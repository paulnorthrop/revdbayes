# Newlyn sea surges

The vector `newlyn` contains 2894 maximum sea-surges measured at Newlyn,
Cornwall, UK over the period 1971-1976. The observations are the maximum
hourly sea-surge heights over contiguous 15-hour time periods.

## Usage

``` r
newlyn
```

## Format

A vector of length 2894.

## Source

Coles, S.G. (1991) Modelling extreme multivariate events. PhD thesis,
University of Sheffield, U.K.
